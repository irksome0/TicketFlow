# Виправлена анотація до дипломної роботи TicketFlow

## АНОТАЦІЯ

Барилко М.В. Вебсистема управління запитами клієнтів у сервісі з надання IT-послуг. - Рукопис.

Дослідження на здобуття ступеня вищої освіти "бакалавр" за спеціальністю 121 "Інженерія програмного забезпечення", освітньо-професійна програма "Інженерія програмного забезпечення". - Західноукраїнський національний університет, Тернопіль, 2026.

Випускна кваліфікаційна робота присвячена проєктуванню та програмній реалізації вебсистеми управління запитами клієнтів у сервісі з надання IT-послуг. Розроблена система TicketFlow призначена для централізованого обліку клієнтських звернень, контролю їх життєвого циклу, розмежування доступу між користувачами та підтримки багатоклієнтної моделі роботи.

У роботі проаналізовано предметну область управління клієнтськими запитами, визначено основні вимоги до системи та обґрунтовано вибір архітектури програмного продукту. Реалізована система забезпечує автентифікацію користувачів, створення та опрацювання заявок, зміну їх статусів, роботу з вкладеннями, SLA-engine з урахуванням робочого календаря та керування користувачами відповідно до їхніх ролей.

Серверну частину системи реалізовано мовою Go з використанням PostgreSQL, а клієнтську частину - на основі Next.js і TypeScript. Практичне значення роботи полягає у створенні програмного продукту, який може бути використаний IT-компаніями для впорядкування процесу обробки клієнтських звернень і підвищення прозорості роботи сервісної команди.

Ключові слова: вебсистема, заявка, IT-сервіс, REST API, Go, Next.js, PostgreSQL, JWT, SLA, багатоклієнтність, рольовий доступ, вкладення.

## ANNOTATION

Barylko M.V. Web-based customer request management system for an IT service provider. - Manuscript.

Bachelor's thesis for the educational degree "Bachelor" in specialty 121 "Software Engineering", educational and professional program "Software Engineering". - West Ukrainian National University, Ternopil, 2026.

The bachelor's qualification thesis is devoted to the design and software implementation of a web-based customer request management system for an IT service provider. The developed TicketFlow system is intended for centralized registration of customer requests, ticket life cycle control, role-based access separation, and support for a multi-tenant operating model.

The thesis analyzes the subject area of customer request management, defines the main system requirements, and substantiates the selected software architecture. The implemented system supports user authentication, ticket creation and processing, status changes, attachment handling, an SLA engine based on a business calendar, and user management according to assigned roles.

The server side of the system is implemented in Go using PostgreSQL, while the client side is based on Next.js and TypeScript. The practical value of the thesis lies in the development of a software product that can be used by IT companies to organize customer request processing and improve the transparency of service team operations.

Keywords: web-based system, ticket, IT service, REST API, Go, Next.js, PostgreSQL, JWT, SLA, multi-tenancy, role-based access, attachments.
